# Site de Aniversário — Ana

Instruções rápidas:

- Coloque a foto que você enviou em `images/ana_e_eu.jpg` dentro da pasta do projeto (crie a pasta `images`).
- Abra o arquivo [index.html](index.html) no navegador para ver o site.

Descrição:

Este é um site de página única, em tom vinho com detalhes dourados e preto. O texto é em português e transmite carinho, sem exagero.

Se quiser que eu incorpore a imagem diretamente no projeto, faça o upload do arquivo de imagem para a pasta `images` e eu atualizo o layout (ou eu posso inserir uma versão otimizada se desejar).
